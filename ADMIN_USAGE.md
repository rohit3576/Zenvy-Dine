# Admin Usage Guide

## Live Orders
Use Live Orders to confirm orders, update payment-aware service status, and print receipts.

Recommended flow:

1. `PENDING`
2. `CONFIRMED`
3. `PREPARING`
4. `READY`
5. `SERVED`
6. `COMPLETED`

## Kitchen Display System
KDS shows only confirmed and preparing orders. Kitchen staff should move confirmed orders to preparing, then ready.

## Waiter Calls
Customer table screens include a waiter call button. Open calls appear in Admin > Waiter Calls and can be marked attended.

## Table Management
Add tables, download QR codes, or print all QR cards. QR URLs use the restaurant slug and table number.

## Settings
Owners and managers can update customer theme color, GST, service charge, and WhatsApp notification phone.

## Receipts
Open an order in Live Orders and use the receipt icon to generate a printable invoice.
